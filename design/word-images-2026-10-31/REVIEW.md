# 이미지 확인 기록

2026-10-31. 기본 제공 `image_gen`으로 신규 단어 이미지 12장을 생성했다. 기존 고양이 v2를 스타일 참고로 사용했으며 기존 3장은 교체하지 않았다.

- 생성 결과 12장을 직접 확인했다. 단어별 중심 장면이 있고, 읽을 수 있는 정답 글자·숫자·워터마크가 없다. 확인 그림의 체크 표시는 의도한 비문자 기호다.
- 신규 12장 모두 1448×1086, RGBA PNG이다. 원본의 알파 최솟값 0과 최댓값 255를 확인했다. 해상도·투명도 후처리는 하지 않았다.
- 생성 도구의 원본은 보존하고 선택한 12장을 프로젝트의 `design/art-direction-2026-10-29/assets/`에 복사했다. 파일 크기와 SHA-256은 `manifest.json`에 기록했다.
- 브라우저의 이미지 모아보기에서 이미지 15개가 모두 로딩됐고 깨진 파일이 없었다. 실제 화면 너비 543px에서 문서 가로 넘침이 없었다.
- 단어장 시안에서 약속을 검색해 `約束` 한 항목과 `card-promise-v1.png`가 표시·로딩되는 것을 확인했다.
- 이번 환경에서는 브라우저 스크린샷 저장 기능이 캡처 오류를 반환해 웹 화면 캡처는 남기지 못했다. 생성 이미지 자체는 각 생성 결과로 확인했고, 웹 파일 연결은 DOM 및 이미지 로딩 상태로 확인했다.
- `polished-ui/art.js` 문법 확인 통과. 실제 앱의 개발 파일·콘텐츠·배포 미디어는 수정하지 않았다.

추상어 그림은 기억을 돕는 장면이다. 뜻이나 허용 정답을 새로 정의한 것이 아니다. 적용 기준은 `HANDOFF.md`, 장면별 생성 명세는 `prompts.json`을 따른다.
