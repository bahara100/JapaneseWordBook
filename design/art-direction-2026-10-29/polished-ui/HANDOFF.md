## 이번 디자인의 방향

짙은 숲색 메뉴와 따뜻한 종이색 본문을 대비시켜 브랜드의 중심을 잡는다. 사진 같은 이미지는 추가하지 않고, 승인한 가벼운 2D 그림을 사용한다. 넓은 여백, 크기가 분명한 글자, 일정한 모서리와 얇은 구분선으로 화면 전체를 통일한다.

본문은 한국어·일본어를 읽기 쉬운 고딕 계열을 사용한다. 단어·문법 표현과 일본어의 짧은 문구에만 기기의 명조 계열을 보조 사용한다. 원격 폰트·새 라이브러리는 추가하지 않았다. 필수 텍스트는 색 대비와 크기를 실제 기기에서 유지한다.

## 화면별 적용

- **공통 메뉴:** PC는 짙은 초록 바탕, 현재 메뉴만 밝은 배경. 메뉴 아래 문구는 부가 장식이며 작은 화면에서는 숨긴다. 모바일은 밝은 상단 브랜드와 하단 메뉴로 전환한다. 하단에서 현재 메뉴 아이콘에만 연한 배경을 넣는다.
- **홈:** 오늘의 학습 패널 하나를 중심으로 구성. 글·학습 정보·시작 버튼은 왼쪽, 따뜻한 바탕 위 고양이는 오른쪽. 모바일에서는 버튼을 먼저 보여주고 그림을 가로로 긴 작은 영역에 배치한다. 아래 세 단계는 학습 방법 설명이며 다른 탭으로 가는 링크가 아니다.
- **학습 앞면:** 그림은 연한 세이지색 영역 안에 전체가 보이게 배치한다. 질문·말하기·직접 입력 순서가 또렷하게 보이도록 한다. 도움말과 시안 채점 예시는 접어둔다.
- **직접 입력:** 입력을 열면 그림이 작아진다. 작성한 답 → 지우기 → 히라가나·가타카나 후보 → 영문 입력 → 정답 확인 순서를 유지한다. 실제 입력·가나 변환 로직은 기존 앱의 것을 사용한다.
- **학습 뒷면:** 일본어 단어를 가장 크게, 가나·한국어 뜻·발음·예문 순서. 예문은 종이색 상자에 묶는다. 정답·재학습 상태의 의미와 문구는 실제 채점 결과에 맞춘다.
- **단어장·즐겨찾기:** 검색·수준 필터를 하나의 패널에 묶고, 목록은 가벼운 흰 패널 안의 행으로 표시한다. 선택한 행에는 연한 초록 바탕과 가는 왼쪽 표시를 사용한다. 즐겨찾기는 별 모양의 채움과 `aria-pressed`를 함께 유지한다.
- **문법:** 단어장과 같은 목록·상세 배치. 일본어 표현은 명조 계열로 강조하고, 접속 형태·사용 방법·예문·주의점은 일정한 간격으로 나눈다.
- **설정:** 하나의 흰 패널 안을 구분선으로 나눈다. PC는 항목 이름과 설정값을 한 줄에, 모바일은 위아래에 놓는다. 목표 카드 수는 연한 초록색 선택 상태로 표시한다.

PC 메뉴는 1080px부터 표시한다. 단어장·문법의 목록/상세 2열은 720px부터 표시하고, 아래에서는 상세를 목록 아래로 이동한다. 1080–1279px 구간은 본문 안쪽 여백과 홈 제목을 함께 줄인다.

## 기존 요청과 기능을 유지할 것

- **N1~N5와 하루 카드 수는 설정에서만 변경한다.** 홈은 현재 값의 읽기 전용 요약만 보여준다.
- 홈의 “조금 더 둘러보기” 링크 모음을 다시 넣지 않는다. 모바일 하단 탭과 PC 메뉴가 이동을 담당한다.
- 한국어 키보드 사용자를 위한 영문 입력과 가나 선택을 유지한다. 조합 입력·Enter·지우기·실제 채점 로직을 교체하지 않는다.
- 실제 앱의 날짜·시간대·카드 배정·진행 중 세션·기록 저장·즐겨찾기를 유지한다.
- 콘텐츠 로딩, 빈 상태, 저장 실패·불가 경고, 오류와 음성 기능의 연결 상태를 가리지 않는다.
- 키보드 포커스, 접근 가능한 이름, 상태 알림, `aria-current`·`aria-pressed`를 유지한다. 줄어든 움직임 설정을 존중한다.
- 디자인의 그림 영역은 `object-fit: contain`. 학습 카드 앞면에는 정답 단어를 표시하지 않는다.

이미지는 `../assets/card-cat-v2.png`, `card-school-v2.png`, `card-apple-v2.png`와 2026-10-31 추가한 `card-{key}-v1.png` 12장이다. 모두 투명 PNG, 1448×1086이다. 기존 3장의 ID 매핑은 상위 `asset-manifest.json`, 추가 12장은 `../../word-images-2026-10-31/manifest.json`과 `HANDOFF.md`를 따른다. 현재 15개 샘플 단어의 그림을 모두 새 스타일로 연결했다. 모아보기는 `/word-images.html`이다.

## 시안과 실제 앱의 차이

샘플 단어 15개·문법 5개를 사용한다. 학습은 수준별 샘플 3장이다. 검색·즐겨찾기·영문 변환·탭 이동·설정은 시안에서 체험할 수 있지만, 새로고침하면 초기화된다. 음성·발음 평가·실제 정답 채점·영구 저장·날짜별 카드 배정은 연결하지 않았다.

`app.js`와 `content.js`는 화면 참고용이다. 실제 React 앱의 로직을 이 파일로 덮어쓰지 않는다. 시안 배너·샘플 문구·“시안 데이터” 영역은 배포 화면에 옮기지 않는다. 설정의 실제 학습 기록 상태를 유지한다.

이번 작업은 `design/`의 새 시안과 연결 안내만 추가했다. 개발 중인 `src/`, `content/`, `public/`는 수정하지 않았다.
