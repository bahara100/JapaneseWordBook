# 디자인 확인 기록 · 03

2026-10-30. 독립 화면 시안을 검토한 기록이다. 실제 React 앱 전체 테스트를 대신하지 않는다.

## 화면과 동작

- PC와 모바일에서 홈·학습·단어장·문법·즐겨찾기·설정 화면을 확인했다.
- 홈 → 학습 시작 → 직접 입력 → `neko` → `ねこ`/`ネコ` 후보 표시 → 히라가나 선택 → 답안 표시 → 카드 뒷면을 확인했다.
- 카드 뒷면의 즐겨찾기 추가 후 즐겨찾기 목록에 단어가 나타나는 것을 확인했다.
- 설정에서 N4 및 하루 20장 선택을 확인했다. 설정값은 시안의 메모리 상태이며 날짜별 실제 적용을 검증한 것은 아니다.
- 단어 검색에 `사과` 입력 후 `りんご` 한 행과 해당 상세·새 PNG 그림이 표시되는 것을 확인했다.
- JavaScript 문법 검사: `app.js`, `art.js`, `preview.mjs` 통과.
- 기존 가나 변환 검사: 26개 예시 및 미완성·잘못된 입력 검사 통과.
- 마지막 브라우저 콘솔 오류 조회 결과 없음.

## 반응형

실제 브라우저 CSS 너비 320, 768, 1080px에서 6개 기본 화면을 각각 확인했다. 모든 화면에서 문서의 가로 넘침과 깨진 이미지가 없었다. 390px 모바일 및 1440px PC에서 주요 화면을 캡처했다.

좁은 홈 그림 영역에서 일본어 문구의 폭이 부모보다 넓어지는 문제를 발견해 줄바꿈으로 수정했다. 수정 후 320px 및 390px 화면에서 문구 폭이 부모 영역 안에 들어오는 것을 확인했다.

## 시각 비교

1440×1000의 같은 크기에서 이전 `clean-ui/#/home`과 새 `polished-ui/#/home`을 캡처해 함께 비교했다. 파일은 `screenshots/before-home-desktop.jpg`, `home-desktop.jpg`다.

새 디자인은 232px 숲색 메뉴, 크림색 본문, 25px 모서리의 시작 패널과 따뜻한 그림 배경을 사용한다. 제목·동작·그림의 위계가 분명하고 이미지가 잘리거나 늘어나지 않는 것을 확인했다. 학습 방법은 단순한 설명 세 칸으로 두고 중복 이동 링크를 추가하지 않았다.

## 글자와 접근성

주요 색 조합의 계산상 대비는 보조 글자/화면 약 4.87:1, 홈 초록 제목/카드 약 5.05:1, 그림 캡션/그림 배경 약 4.75:1, 흰 버튼 글자/주요 버튼 약 7.78:1이다. 이는 지정 색 조합 검사이며 사이트 전체의 접근성 인증은 아니다.

모바일 입력은 16px, 주요 동작은 높이 약 48px이다. 키보드 포커스와 메뉴·선택 상태의 접근성 속성을 유지했다. 줄어든 움직임 설정을 위한 CSS를 포함했다.

실제 음성·발음 평가·정답 채점·영구 저장·날짜별 카드 배정은 이 시안에 연결하지 않았다. 실제 앱에 적용할 때 지켜야 할 기능은 `HANDOFF.md`에 정리했다.
