# 하루일본어 — 이미지·디자인 전달서 01

작성일: 2026-10-29 / 최신 스타일: 가벼운 2D v2 / 범위: 첫 카드 이미지 세트와 시각 디자인 기준

## 담당 구분

클로드는 앱 개발과 연결을 담당하고, 이 폴더는 이미지·화면 디자인 산출물을 제공한다. 이번 작업에서는 src/, content/, public/의 기존 구현을 수정하지 않았다. 이미지의 실제 적용 여부와 디자인 제작 완료를 구분한다.

## 완성한 산출물

- `assets/card-cat-v2.png`: 고양이. 주황·크림색 털, 편안하게 앉은 자세.
- `assets/card-school-v2.png`: 학교. 교실 창문·시계·주출입구가 보이는 건물.
- `assets/card-apple-v2.png`: 사과. 줄기와 잎이 있는 붉은 사과 한 개.
- `index.html`: 이미지와 카드 배치를 검토하는 디자인 보드. 실제 학습 앱이 아니다.
- `card-art.css`: 기존 화면에 연결할 때 참고하는 이미지 전용 CSS. 아직 앱에 import하지 않았다.
- `design-tokens.css`: 색상·글자·여백 기준. 현재 앱의 크림색·초록색 디자인과 맞춘다.
- `asset-manifest.json`: 실제 크기·파일 용량·대응 word/media ID와 권장 배포 경로.
- `prompts-v2.json`: 최신 가벼운 2D 편집 프롬프트 원문. 초기 생성 프롬프트는 prompts.json에 보존했다. 외부 API 키나 별도 이미지 서비스는 사용하지 않았다.

## 스타일 기준

목표는 성인도 편안하게 사용할 수 있는 일본어 학습 노트다. 크림색 종이와 짙은 초록색을 바탕으로, 단순한 색면과 둥근 형태, 명확한 실루엣을 사용한다. 사용자의 피드백에 따라 실사에 가까운 털·재질·피부 질감을 제외하고, 작은 카드에서도 읽히는 가벼운 2D 일러스트로 통일한다. 미세한 사실적 묘사 대신 최소한의 눈·코·선·창문 등으로 대상을 표현한다.

- 그림에는 일본어·한국어·로마자·번호·워터마크를 넣지 않는다.
- 한 카드에는 하나의 주된 의미를 담는다. 고양이에 먹이·장난감 등 경쟁하는 소재를 추가하지 않는다.
- 그림 자체에 테두리·버튼·카드 그림자·UI를 그리지 않는다. 화면의 카드 디자인은 코드로 분리한다.
- 투명 PNG는 배경에 얹어 사용한다. 화면에서 검은 배경이 보이면 PNG 원본의 알파가 아니라 표시/변환 과정부터 확인한다.
- 가장자리까지 오는 부분이 있으므로 화면 내부 패딩을 별도로 둔다. 파일을 자르거나 늘려서 슬롯을 채우지 않는다.
- 학교처럼 가로로 긴 대상과 고양이처럼 세로로 긴 대상은 같은 4:3 이미지 영역 안에 `object-fit: contain`으로 배치한다.

## 화면별 적용

### 홈

지금의 단일 학습 시작 영역과 겹친 종이 카드 배치를 유지한다. 카드 안의 고양이 그림만 새 자산으로 연결할 수 있다. 장식용 미리보기에 들어가는 단어·뜻은 HTML 텍스트로 유지하며 이미지에 합치지 않는다. 이 예시는 현재 학습 수준에 따라 바뀌는 실제 출제 카드가 아니다.

홈에 수준 선택·학습량 조절·중복 둘러보기 메뉴를 다시 추가하지 않는다. 해당 조작은 설정과 탐색 메뉴에 남긴다.

### 학습 카드 앞면

그림은 4:3 영역 안에 배치한다. PC는 최대 365×274px, 모바일은 영역 너비에 맞추되 그림이 입력/다음 동작을 밀어내지 않게 한다. 영문 입력을 펼쳤을 때는 그림을 130~160px 높이로 줄일 수 있다. 그림 안에 정답을 표시하지 않는다.

말하기와 직접 입력은 같은 크기의 버튼을 사용하고, 직접 입력 후보는 입력 칸 위에 히라가나/가타카나 두 열로 둔다. 로마자→가나 변환 규칙과 채점은 개발 담당 영역으로 유지한다.

### 뒷면·단어 상세

일본어 단어 40~58px, 읽기 20~24px, 한국어 뜻 16~20px로 위계를 준다. 예문·읽기·번역은 연한 배경으로 한 묶음에 둔다. 출제 상태·정답 표기·즐겨찾기 동작은 기존 구현을 유지한다.

### 모바일

- 단일 열, 화면 좌우 여백 16~20px.
- 주요 버튼 터치 영역 최소 44px, 학습 시작/입력 완료는 약 48px.
- 직접 입력 글자 크기 16px 이상.
- 하단 탭과 safe-area 영역을 본문 아래 여백에 반영한다.
- 고정 높이로 그림의 위아래를 자르지 않는다.

## 데이터 연결표

| 자산 | 기존 word ID | 기존 media ID | 기존 경로 | 권장 새 경로(public 기준) |
| --- | --- | --- | --- | --- |
| 고양이 | w001 | img-cat | media/images/cat.svg | media/images/card-cat-v2.png |
| 학교 | w002 | img-school | media/images/school.svg | media/images/card-school-v2.png |
| 사과 | w003 | img-apple | media/images/apple.svg | media/images/card-apple-v2.png |

위 ID와 원래 경로는 현재 `content/n5/words.json`에서 읽은 값이다. 연결할 때는 다시 현재 데이터를 확인한다. 기존 word/media/prompt ID를 바꾸지 않는다. 이미 저장된 학습 기록과 세션 스냅샷을 고려해 이전 SVG도 당분간 유지한다.

## 클로드 적용 순서

1. 새 PNG를 `public/media/images/`에 복사한다. 원본은 이 디자인 폴더에 유지한다.
2. `content/n5/words.json`의 해당 media.path를 새 경로로 갱신하고, 생성 파일인 `public/content/`는 직접 편집하지 않는다.
3. 홈의 고정 고양이 미리보기 경로도 함께 확인한다. 프로젝트 하위 주소에서는 기존 mediaUrl 유틸리티를 사용한다.
4. `card-art.css`의 이미지 맞춤 규칙을 기존 스타일 계층에 통합한다. 클래스 추가가 필요하면 개발 담당이 연결한다.
5. 배포용 크기/포맷 최적화가 필요하면 별도 사본을 만든다. PNG 원본의 알파와 그림 비율을 유지한다.
6. 기존 콘텐츠 검사·빌드와 해당 화면 검증을 수행한다. 작은 모바일 화면과 큰 PC에서 전체 대상이 보이는지, 후보 선택/즐겨찾기/학습 이어하기가 유지되는지 확인한다.

v2 파일의 실제 용량은 asset-manifest.json에 기록했다. v1 PNG와 이전 manifest·보드는 비교용으로 보존했으며 신규 적용은 v2 파일을 사용한다. 현재 세트는 원본 제공이며 WebP/AVIF 최적화 사본은 포함하지 않았다. 자산 메타데이터의 실제 바이트 수를 기준으로 배포 정책을 정한다.

## 검수 상태

생성 결과의 소재, 글자 없음, 투명 알파, 4:3 비율과 파일 복사를 확인했다. 학교·고양이·사과 그림은 디자인 검토용 첫 세트이며 JLPT 수준 분류·학습 효과·교육 콘텐츠 검수 완료를 의미하지 않는다. 생성 이미지를 공개 콘텐츠로 채택할지는 프로젝트의 콘텐츠 검수 단계에서 결정한다.

이번 세트에 포함되지 않은 N4~N1 단어 그림은 기존 SVG가 유지된다. 다음 제작에서는 준비·약속·운전 같은 구체적 상황부터 같은 스타일로 확장한다. 추상어는 하나의 그림만으로 정답이 모호해질 수 있어 문맥 설계를 먼저 검토한다.
