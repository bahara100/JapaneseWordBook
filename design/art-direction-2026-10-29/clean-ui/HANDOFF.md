## 디자인 목표

장식보다 학습 내용이 먼저 보이도록 여백과 글자 위계를 정리한다. 기존 초록색과 가벼운 2D 그림은 유지한다. 반복되는 소개 문구, 영어 소제목, 겹친 카드 장식, 짙은 그림자와 여러 색 배경을 줄인다.

| 요소 | 기준 |
| --- | --- |
| 화면 배경 / 카드 | `#FAFBF8` / `#FFFFFF` |
| 본문 / 보조 글자 | `#273A30` / `#68736B` |
| 주요 동작 / 선택 배경 | `#2B6049` / `#EDF3E9` |
| 구분선 | `#E5E9E1`, 1px |
| 모서리 | 버튼·입력 8px, 카드 12–14px |
| 제목 / 본문 | PC 28px / 14px, 모바일 24–26px / 14px |
| 입력 글자 | 모바일 16px 이상 |
| 버튼 | 주요 동작 높이 46–48px, 작은 아이콘 조작 영역 44px |
| PC | 좌측 메뉴 208px, 본문 최대 1080px, 좌우 안쪽 여백 40px |
| 모바일 | 단일 열, 좌우 여백 16–20px, 하단 5개 탭, 안전 영역 반영 |

PC 메뉴는 1080px부터, 목록과 상세의 2열 배치는 720px부터 사용한다. 좁은 화면에서는 목록 아래에 상세를 두고, 항목 선택 시 상세 제목으로 이동한다. 실제 사용 영역에서 일본어·한국어가 자연스럽게 줄바꿈되도록 확인한다.

## 실제 코드에 적용할 때

이 폴더의 HTML·JS는 예전 화면 시안의 샘플 컨트롤러다. **실제 앱의 컴포넌트·저장소·학습 로직을 이 파일로 교체하지 않는다.** 스타일도 전체 복사하지 말고 실제 컴포넌트에 맞춰 정리한다.

| 실제 파일 | 적용 범위 |
| --- | --- |
| `src/shell/AppShell.tsx` | PC 메뉴·모바일 탭·상단 배치, 간결한 브랜드 |
| `src/pages/PageTitle.tsx` | 제목 크기, 짧은 설명, 장식용 영어 소제목 제거 |
| `src/pages/Home.tsx` | 단일 시작 패널, 읽기 전용 수준·카드 수, 가벼운 그림 |
| `src/pages/Study.tsx` | 카드 중심 단일 열, 접을 수 있는 도움말, 앞·뒷면 위계 |
| `src/study/KanaAnswer.tsx` | 후보 2열, 입력·지우기 배치, 모바일 입력 16px |
| `src/pages/Settings.tsx` | 설정 항목과 저장 상태를 유지하면서 간격·열 배치 정리 |
| `src/styles/base.css`, `polish.css`, `app.css` | 위 기준으로 기존 스타일에 반영하고 중복 규칙 정리 |
| 단어장·문법·즐겨찾기 구현 시 | 이 시안의 목록·검색·상세 레이아웃 참고 |

다음 기능은 현재 실제 앱의 동작 그대로 유지한다.

- N1~N5와 하루 학습량은 **설정에서만 변경**한다. 홈에 선택 버튼을 다시 추가하지 않는다.
- 홈에 제거한 “조금 더 둘러보기” 링크 모음을 다시 추가하지 않는다.
- 진행 중인 세션의 설정 유지, 날짜·시간대에 따른 다음 학습일 적용, 실제 카드 수와 선택 로직.
- 영문→가나 변환, 후보 선택·Enter·지우기·조합 입력, 실제 답안 채점과 실패 상태.
- 즐겨찾기, 저장 성공·실패, 저장소 접근 문제, 콘텐츠 로딩·오류·빈 상태, 세션 재개·요약.
- 키보드 포커스, 접근 가능한 이름, `aria-current`·`aria-pressed`, 상태 알림과 오류 메시지.

긴 개발 설명은 정리하되, 사용자가 다음 행동을 결정하는 데 필요한 오류·기록 저장 상태·아직 연결되지 않은 음성 기능 안내는 숨기지 않는다. 시안의 “시안 데이터” 항목과 샘플 배너는 배포 화면에 옮기지 않는다. 실제 설정에서는 학습 기록 상태를 보여준다.

## 이미지

`../assets/card-cat-v2.png`, `card-school-v2.png`, `card-apple-v2.png`를 사용한다. 모두 투명 PNG 1448×1086, 4:3이다. `object-fit: contain`으로 전체 그림을 표시하며, 잘라내거나 늘리지 않는다. 다른 단어의 그림은 기존 SVG를 임시 사용했다.

자세한 이미지 ID 매핑과 적용 경로는 상위 폴더의 `HANDOFF.md`, `asset-manifest.json`을 따른다. 학습 카드 앞면에 정답 텍스트를 얹지 않는다.

## 시안 동작의 범위

홈·학습·단어장·문법·즐겨찾기·설정 화면을 탐색할 수 있다. 샘플 단어 15개, 문법 5개이며 학습은 선택 수준의 샘플 3장이다. 검색·즐겨찾기·영문 변환은 메모리에서만 체험한다. 실제 음성, 정밀 발음 평가, 실제 정답 채점, 날짜별 카드 배정과 영구 저장은 이 시안에 연결하지 않았다. 새로고침하면 초기화된다.

이번 작업은 `design/art-direction-2026-10-29/`에만 추가했다. 실제 앱의 `src/`, `content/`, `public/`는 수정하지 않았다.
