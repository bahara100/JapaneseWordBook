# 시안 확인 기록

2026-10-29. 독립 디자인 시안만 확인했으며 실제 React 앱의 검증 기록은 아니다.

- JavaScript 문법 확인: `app.js`, `art.js` 통과.
- 기존 가나 변환 확인: 26개 예시 및 미완성·잘못된 입력 검사 통과.
- 브라우저에서 홈·학습·단어장·문법·즐겨찾기·설정 메뉴 탐색 확인.
- 학습 시작 → 직접 입력 → `neko` 입력 → `ねこ`/`ネコ` 후보 표시 → 히라가나 선택 → 답안 표시 → 카드 뒷면 확인.
- 카드 뒷면에서 즐겨찾기 추가 후 즐겨찾기 목록에 표시되는 것 확인.
- 설정에서 수준·카드 수·시간대·로마자·발음 속도 항목 배치 확인. 시간대와 음성 속도는 시안의 선택 상태만 바뀐다.
- 실제 브라우저 CSS 너비 317px와 355px에서 6개 기본 화면의 문서 가로 넘침 없음, 깨진 이미지 없음.
- 실제 CSS 너비 약 1422px 및 1600px에서 PC 메뉴와 2열 배치 확인. 뷰포트 도구 요청 크기와 실제 CSS 크기가 달라 실제 읽은 값을 기록했다.
- 제목의 프로그램 포커스 테두리는 제거하고 버튼·링크·입력·선택·접기 제목의 키보드 포커스 표시는 유지.
- 마지막 브라우저 콘솔 오류 조회 결과 없음.
- 캡처는 `screenshots/`에 저장. 브라우저 제공 캡처의 확대/축소로 글자가 흐리게 보일 수 있어 실제 HTML 미리보기를 우선한다.

실제 음성·발음 평가·정답 채점·영구 저장·날짜별 학습 배정은 이 시안의 확인 범위에 포함하지 않았다. 실제 앱의 상태·오류·저장 메시지를 유지하는 적용 기준은 `HANDOFF.md`에 정리했다.
