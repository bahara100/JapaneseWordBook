# 첫 이미지 세트 확인 기록

확인일: 2026-10-29

## 최신 변경 — 가벼운 2D v2

- 사용자의 피드백을 반영해 고양이·학교·사과의 미세한 재질 묘사를 줄이고 둥근 형태·넓은 색면 중심으로 다시 제작했다.
- 고양이 v2를 먼저 제작하고, 학교·사과 편집에서는 이 그림을 스타일 기준으로 사용했다. 내장 ImageGen 편집 프롬프트는 prompts-v2.json에 보관했다.
- 세 v2 파일 모두 1448×1086px RGBA PNG이며, 알파 범위 0~255를 확인했다. 파일 목록과 전달서, 디자인 보드는 v2를 사용하도록 갱신했다.
- v1 이미지, asset-manifest-v1.json, index-v1.html은 비교용으로 보존한다.
- 이번 갱신에서는 브라우저 연결 API가 'browser.user is unavailable'을 반환해 보드 자동 새로고침과 화면 확인은 완료하지 못했다. 파일 경로·크기·투명도와 생성 이미지 자체는 확인했다.
- 앱 코드와 학습 로직은 변경하지 않았다. 실제 앱 연결은 클로드 담당이다.

## 이미지

- 내장 ImageGen으로 고양이·학교·사과를 각각 생성했다. 프롬프트는 prompts.json에 보관했다.
- 세 파일 모두 1448×1086px(4:3), RGBA PNG이며 알파 범위 0~255를 확인했다.
- 생성된 이미지를 직접 확인했다. 일본어/한국어 정답 글자와 UI 프레임이 없고, 각 대상 전체가 보인다.
- 원본을 프로젝트 내 assets/로 복사했다. 파일 크기와 SHA-256은 asset-manifest.json에 기록했다.
- 이미지 내용 수정·크롭·합성·손실 압축은 하지 않았다. 배포용 경량 사본은 별도 작업이다.

## 디자인 보드

- 별도의 로컬 정적 서버에서 열었고, 보드의 다섯 img 요소(재사용 포함)가 모두 정상 로딩된 것을 확인했다.
- 브라우저 DOM의 실제 문서 너비 526px·1405px·416px에서 가로 넘침이 없었다.
- 모바일 배치에서는 카드 목록이 한 열이 되는 것을 확인했다. 실제 기기 테스트를 뜻하지 않는다.
- 현재 브라우저의 화면 캡처 API가 'Unable to capture screenshot'을 반환해 보드 화면의 스크린샷은 저장하지 못했다. 이미지 자체의 검토와 DOM 기반 확인을 전체 화면 시각 QA로 주장하지 않는다.
- 개발 앱의 미리보기(4173)는 접속되지 않았다. 디자인 보드는 4176의 별도 서버로 검토했고 앱 코드·콘텐츠·개발 서버 설정은 변경하지 않았다.

## 적용 상태

아직 앱에 연결하지 않은 디자인 산출물이다. 실제 앱에 연결한 뒤 이미지 잘림, 모바일의 버튼 위치, 기존 학습 기록·채점 동작을 개발 담당이 검증한다. 현재 N5 첫 세 장만 신규 이미지이며 나머지 수준의 이미지를 완성했다고 표기하지 않는다.

## 보드 다시 열기

보드 폴더에서 아래 명령을 실행한 다음 로컬 주소를 연다. 이미 서버가 켜져 있다면 다시 실행할 필요가 없다.

```powershell
python -m http.server 4176 --bind 127.0.0.1
```

주소: http://127.0.0.1:4176/
