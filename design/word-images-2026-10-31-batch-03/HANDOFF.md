# N5 단어 이미지 추가 · 세 번째 묶음

2026-10-31. 현재 콘텐츠의 N5 w031–w045에 맞춰 15장을 추가했다. 기존 그림은 교체하지 않았으며 기존 단어 ID를 유지한다.

## 확인과 파일

- 이번 추가 그림 바로 보기: http://127.0.0.1:4176/word-images.html#latest-images
- 원본 저장: `../art-direction-2026-10-29/assets/card-{key}-v1.png`
- 원본·실제 크기·알파·파일 크기·해시·단어 연결: `manifest.json`
- 실제 사용한 생성 프롬프트와 참고 이미지: `prompts.json`
- 250개 단어의 이미지 준비 현황: `coverage.json`
- 누적 45장 카탈로그: `../art-direction-2026-10-29/image-catalog.json`

기본 제공 `image_gen`을 사용했다. 고양이 v2를 스타일 참고로 사용했고, 내일 그림에는 오늘 그림도 추가 참고로 넣어 달력 모양을 맞췄다. 모든 신규 원본은 실제 알파가 있는 RGBA PNG, 약 4:3 비율이다. 해상도·투명도를 후처리하지 않았다. 파일별 크기는 manifest의 실제 값을 사용한다.

## 실제 앱 적용

실제 `src/`, `content/`, `public/`는 수정하지 않았다. 새 이미지·모아보기·디자인 시안의 그림 매핑만 추가했다. 디자인 시안의 학습용 샘플 단어 데이터는 기존 15개를 유지한다.

개발 담당 Claude가 새 단어 이미지를 적용할 때:

1. 신규 PNG를 배포 미디어 폴더에 복사한다. `proposedPublicPath`는 제안 경로이며 실제 빌드 규칙에 맞춘다. WebP로 최적화한다면 투명도를 유지하고 원본 PNG를 보관한다.
2. 기존 프롬프트 ID `w031-p1`–`w045-p1`을 유지하고 `imageAssetId`를 연결한다.
3. 해당 수준 파일의 `media` 배열에 새 이미지 레코드를 추가한다. 제안 ID `proposedMediaId`의 충돌 여부를 확인한다.
4. 기존 미디어 스키마에 맞춰 이미지 경로·보이는 장면 설명·생성 출처를 기록한다.
5. 기존 읽기·뜻·허용 표기·검수 상태·카드 선택·채점 로직은 유지한다. 정답 글자를 그림 위에 얹지 않는다.
6. `object-fit: contain`으로 전체 그림을 보이고 비율을 늘리거나 잘라내지 않는다.

## 문맥이 필요한 단어

이름은 빈 이름표를 가리키는 모습, 오늘·내일은 현재 칸과 다음 칸, 가다·오다는 관찰자에게서 멀어짐과 다가옴으로 표현했다. 이런 그림은 뜻을 떠올리는 보조 자료이며 그림만으로 정답이 유일해지지는 않는다. 출제 검수에서 적절한 질문·예문 맥락을 함께 확인한다. manifest에 `needsLearningContext`로 표시했다.

먹다·마시다·보다·듣다는 행동이 드러나도록 사람의 동작을 중심으로 표현했다. 듣다 그림은 `聞く`의 듣기 의미를 보여주며, 묻기 의미까지 시각화한 것은 아니다.

## 현황과 다음 순서

현재 등록 250개 단어 중 디자인 이미지 준비는 45개, 미제작은 205개다. N5는 33개 준비·17개 미제작이며 다른 수준은 각각 3개 준비·47개 미제작이다. 실제 배포 적용 수와는 구분한다.

현재 후속 제작의 시작은 `w046 読む`(읽다), `w047 書く`(쓰다), `w048 話す`(말하다)이다. 자세한 순서는 coverage의 pending 목록을 따른다. 이 목록은 현재 콘텐츠를 읽은 스냅샷이므로 후속 작업 전에 최신 데이터와 맞춘다.
