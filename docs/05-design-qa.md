## 홈 단순화 반영

- 학습 수준·하루 학습량 선택은 설정 화면에서만 제공하도록 변경했다.
- 홈의 '조금 더 둘러보기'와 단어장·문법·즐겨찾기 중복 링크를 제거했다.
- 브라우저에서 홈에 오늘의 학습 카드와 시안 안내만 표시되고, 설정에는 수준 선택과 하루 10/15/20장 조절이 남아 있는 것을 확인했다.
- 단일 파일 시안과 PC·모바일 홈 이미지를 갱신했다.

## 영문 자판 입력 반영

- 로마자 입력 위에 히라가나/가타카나 후보를 표시하고 선택한 문자를 답안에 추가한다. 외부 서비스나 일본어 자판 설치는 필요하지 않다.
- 26개 로마자·가나 변환 예제와 미완성/변환 불가 입력 검사를 통과했다. 재확인 명령: `node design/kana-input-check.mjs`.
- 브라우저에서 `neko` → `ねこ / ネコ` 후보, 가타카나 선택, 한 글자/전체 삭제, `gakkou` Enter → `がっこう` 추가 후 문제 유지, `sh`의 미완성 안내, 한국어 입력의 변환 불가 안내를 확인했다.
- 후보를 누르지 않고 로마자 입력 상태에서 '입력 완료'를 눌렀을 때 히라가나로 변환하고 '내가 입력한 답'을 정답 화면에 표시하는 것을 확인했다. 실제 채점은 연결하지 않았다.
- 390px viewport에서 가로 넘침 없이 후보 두 개가 배치되는 것을 확인했다. 확인 시 수집된 warn/error 로그는 없었다.

## 검증 범위의 한계

- 실제 iPhone/Android 기기의 테스트가 아니라 데스크톱 브라우저의 viewport 크기 변경으로 레이아웃을 확인했다.
- 마이크·합성 음성·정답 판정·IndexedDB·날짜별 카드 선정·배포는 이번 시안에 연결하지 않았다.
- 단일 파일을 브라우저 자동화로 직접 여는 작업은 해당 도구의 file: 프로토콜 제한으로 확인하지 못했다. 원본은 로컬 HTTP 브라우저에서 확인했고 내보낸 파일은 스크립트 구문을 확인했다.
- 단어·문법 수준 분류와 해설은 설계용 초안이며 교육 콘텐츠 검수 완료를 의미하지 않는다.
- 키보드·스크린리더·대비의 전면 검수는 실제 앱 구현 단계의 완료 조건으로 남아 있다.

로컬 HTTP 미리보기 서버는 점검 후 종료한다. 이후에는 README의 실행 방법으로 다시 열거나 `design/preview.html`을 사용자의 브라우저에서 직접 열어볼 수 있다.
