# 실제 기기 검수 목록 (백로그 5-2)

자동 화면 테스트는 PC Chrome과 iPhone 흉내(WebKit)에서 매번 돌아가지만, **진짜 소리·진짜 마이크·진짜 휴대폰 화면**은 사람이 확인해야 합니다. 이 목록은 그 부분만 모았습니다.

사이트: https://bahara100.github.io/JapaneseWordBook/

## 확인할 기기

| 기기 | 브라우저 | 왜 |
| --- | --- | --- |
| PC | Chrome | 가장 많이 쓰는 환경. 말하기 인식은 인터넷이 필요 |
| PC | Edge | Windows 기본. 일본어 온라인 음성이 따로 있음 |
| Android 휴대폰 | Chrome (삼성폰이면 Samsung Internet도) | 휴대폰 화면·터치·마이크 |
| iPhone | Safari | 음성·마이크·저장 규칙이 가장 다름 |

한 기기에 10~15분 정도 걸립니다. 다 못 하면 **iPhone Safari → Android Chrome → PC Chrome** 순서가 가장 중요합니다.

## 1. 기기 확인 화면 (모든 기기, 2분)

1. 사이트를 열고 **설정 → 맨 아래 "이 기기에서 저장·듣기·말하기가 되는지 확인하기"** (또는 주소 끝에 `#/check`).
2. **소리 시험 · ねこ** 를 누릅니다. → 일본어로 "네코"가 들리면 성공.
3. **말하기 시험** 을 누르고 "네코"라고 말합니다. 처음엔 마이크 허용을 물어봅니다.
4. **결과 복사** 를 누르고 저(Claude)에게 붙여 넣어 주세요. 복사가 안 되면 아래 글 상자를 길게 눌러 복사합니다.

결과에 "안 됨"이 있어도 괜찮습니다. 그 기기에서는 직접 입력으로 학습하면 되고, 앱이 그렇게 안내하는지가 확인 대상입니다.

## 2. 학습 흐름 (모든 기기, 5분)

처음 쓰는 상태로 보고 싶으면 그 브라우저에서 이 사이트를 처음 여는 것이 좋습니다(다른 기기의 기록은 섞이지 않습니다).

| # | 할 일 | 기대 결과 |
| --- | --- | --- |
| 2-1 | 홈 → **오늘의 학습 시작** | 고양이 그림 카드, "1 / 3장". 그림이 잘리거나 늘어나지 않음 |
| 2-2 | **듣기 힌트** | "네코" 소리. "힌트를 들었어요" 표시 |
| 2-3 | **직접 입력** → `neko` 입력 → 위의 **ねこ** 후보 누르기 → **입력 완료** | 휴대폰 자판이 가리지 않고, "힌트를 듣고 맞혔어요." |
| 2-4 | **발음 듣기**, **예문 듣기** | 각각 일본어로 들림. 누르는 중엔 "정지"로 바뀜 |
| 2-5 | 다음 카드에서 **말하기** → "갓코-"(学校)라고 말하기 | "정답 단어로 인식했어요." + "들은 말" |
| 2-6 | 다음 카드에서 **말하기** → 일부러 다른 말 | 처음엔 "한 번 더 또렷하게 말해 볼까요?", 두 번째에 오답 처리 |
| 2-7 | 결과 화면까지 진행 | 바로 정답/다시 연습/답 확인·힌트 수, "다시 볼 단어" 목록 |
| 2-8 | 학습 중간에 **새로고침**(또는 앱 전환 후 돌아오기) | 같은 카드·같은 위치에서 이어짐 |

마이크를 **거부**해 보는 것도 확인 대상입니다: "마이크를 사용할 수 없어요. 직접 입력으로 계속할 수 있어요." 가 나오고 입력 칸이 열리면 정상입니다.

## 3. 단어장·문법·즐겨찾기 (휴대폰 1대 이상, 3분)

| # | 할 일 | 기대 결과 |
| --- | --- | --- |
| 3-1 | 단어 → 검색창에 `neko`, `학교`, `がっこう` | 각각 맞는 단어 1개 |
| 3-2 | 단어 하나 누르기 → **← 단어 목록으로** | 휴대폰은 상세가 따로 열리고, 돌아가도 검색어 유지 |
| 3-3 | 별 누르기 → 보관함 | 보관한 단어가 보이고, 새로고침해도 남음 |
| 3-4 | 보관함 → **모은 단어 학습하기** | "모아 보는 그림카드" 학습 |
| 3-5 | 문법 → `ながら` 검색 → 상세 → **예문 듣기** | 의미→접속 형태→설명→예문→주의점 순서, 예문 소리 |

## 5. 화면·접근성 (휴대폰 1대, 2분)

- 휴대폰 **가로로 돌리기**: 글자·버튼이 잘리지 않음.
- 브라우저 글자 크기를 크게(또는 PC에서 200% 확대): 가로 스크롤 없이 읽힘.
- (선택) iPhone VoiceOver / Android TalkBack 을 켜고 학습 카드 한 장: 문제 면에서 정답이 읽히지 않고, "정답 보기" 뒤 단어가 읽힘.

## 결과 보내는 방법

기기마다 아래만 보내 주시면 됩니다.

1. 1단계의 **결과 복사** 글
2. 기대와 다르게 된 번호(예: `2-5`)와 무엇이 보였는지. 가능하면 화면 캡처

받은 결과로 지원 범위(어느 기기에서 듣기·말하기가 되는지)를 정리해 문서와 앱 안내에 반영하고, 문제는 고칩니다.

## 사람이 하지 않아도 되는 것

다음은 자동 테스트가 매번 확인하므로 기기 검수에서 빼도 됩니다: 자정 넘김·다음 날 복습 일정, 두 탭 동시 학습, 잘못된 백업 파일 거절, 저장이 막힌 브라우저 안내, 검색 순위, 로마자 변환 규칙.
