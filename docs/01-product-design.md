# 제품·학습 설계 v0.1

작성일: 2026-10-28 / 상태: 구현 기준 초안 / 제품명: 하루일본어(가칭)

## 1. 제품 목표와 기본값

한국어 사용자가 N5~N1 중 자신의 수준을 선택하고, 하루 10~20장의 그림카드로 단어를 익히며 문법 설명과 예문을 찾아볼 수 있게 한다.

- 기본 수준 N5, 하루 목표 15장. 선택지는 10·15·20장.
- 한국어 UI와 뜻풀이, 일본어 단어·읽기·예문.
- PC와 스마트폰 브라우저를 모두 지원한다.
- 최초 버전은 로그인 없이 기기에 기록을 저장한다.
- 첫 배포는 공개 GitHub 저장소와 GitHub Pages를 사용한다.
- 학습 수준과 하루 목표는 설정 화면에서만 변경한다. 오늘 시작한 세션에는 시작 당시 설정을 유지한다.

사용자가 요청한 기능을 보존하되, 정밀 발음 평가는 음성 인식 기반 단어 확인과 구분한다.

## 2. 범위와 단계

| 구분 | 내용 |
| --- | --- |
| 1단계 설계(현재) | 학습 규칙·화면·데이터 계약, PC/모바일 클릭형 시안, 구현 백로그 |
| 첫 공개 버전 | 수준 선택, 오늘의 카드, 복습, 듣기, 지원 환경의 말하기 정답 확인, 단어 검색, 즐겨찾기, 문법, 기기 내 저장, 수동 백업 |
| 후속 확장 | 자동 기기 동기화, 더 많은 콘텐츠, 오프라인 학습, 정밀 발음 평가 |

현재 시안은 영구 저장과 실제 음성 기능을 연결하지 않는다. 카드의 채점 버튼은 결과 상태를 검토하기 위한 예시다.

## 3. 사용자 흐름

### 첫 방문

홈 → 기본값으로 오늘의 학습 시작. 수준·하루 목표를 바꾸려면 설정 → 수준·목표 변경 → 홈 → 학습 시작.

온보딩 모달로 접근을 막지 않는다. 홈에서는 현재 수준과 하루 목표를 요약해서 보여주고, 변경 조작은 설정 화면에만 둔다. 설정에서는 수준·하루 목표와 함께 시간대·음성 속도·로마자 표시를 바꾼다.

### 재방문

홈 → 오늘의 세션 이어하기 → 카드별 답변·정답 확인 → 결과 → 틀린 단어 다시 보기 또는 홈.

단어장·문법은 학습 세션을 끝내지 않아도 접근할 수 있다. 뒤로 이동하거나 화면을 바꿔도 진행 상황을 보존한다.

### 탐색

단어장 → 수준·검색어 입력 → 단어 상세 → 듣기·즐겨찾기.

즐겨찾기 → 수준 필터 → 상세 또는 즐겨찾기 학습. 즐겨찾기 학습은 오늘의 목표 세션과 별도로 집계한다.

문법 → 수준·검색 → 문법 상세 → 접속 형태·예문·주의점 확인.

## 4. 하루 카드 선정 규칙

1. 설정된 시간대의 달력 날짜로 학습일을 정한다. 기본 시간대는 브라우저에서 감지하며 감지 실패 시 Asia/Seoul을 사용한다.
2. 오늘의 학습을 시작할 때만 세션을 만든다. 방문만으로 단어를 소진하지 않는다.
3. 현재 수준의 복습 기한이 된 단어를 최대 약 1/3 배정하고, 남은 수량을 새 단어로 채운다. 목표 10·15·20장일 때 복습 기본 상한은 각각 3·5·7장이다.
4. 복습 후보는 복습일이 오래된 순, 오답이 많은 순, 고유 ID 순으로 정렬한다. 새 단어는 콘텐츠의 curriculumOrder 순으로 선택한다.
5. 새 단어가 부족하면 추가 복습 후보로 채운다. 그래도 부족하면 실제 수량만 제공하며 같은 카드를 중복 생성하지 않는다.
6. 단어 ID, 출제할 의미·읽기, 순서, 수준, 목표, 시간대, 날짜, 콘텐츠 버전을 세션에 고정한다. 새로고침·재방문·수준 변경으로 오늘의 세션을 다시 뽑지 않는다.
7. 설정 변경은 다음 학습일에 반영한다. 다른 수준을 지금 연습하고 싶으면 단어장의 별도 연습을 사용한다.
8. 세션 도중 자정이 지나도 기존 세션은 완료할 수 있다. 완료 후 새 날짜의 세션을 시작한다. 동시에 하나의 세션만 진행한다.

시안에서는 수준별 3장만 제공하며 하루 목표와 구분해 표시한다. 실제 하루 분량이 준비되었다고 오해하게 하지 않는다.

## 5. 카드 상태와 답변

`문제 → 답변 중 → 인식/입력 결과 확인 → 정답 또는 다시 연습 → 정답 공개 → 다음 카드 → 세션 결과`

공통 원칙:

- 기본 학습은 그림 보고 일본어 읽기를 답하는 방식이다. 앞면에 정답 표기·읽기·뜻을 노출하지 않는다.
- 답변 수단: 말하기 또는 영문 자판의 로마자 입력. 로마자를 입력하면 위에 히라가나·가타카나 변환 후보를 보여주고, 선택한 후보를 답안에 추가한다. 일본어 자판 설치 없이 학습을 완료할 수 있다. 가나 붙여넣기도 허용한다.
- Enter는 히라가나 후보를 답안에 추가하며 정답을 공개하거나 제출하지 않는다. '입력 완료' 버튼은 남은 완성 로마자를 히라가나로 변환해 답안에 합친 뒤 확인한다. 미완성 입력·변환 불가 문자는 제출 전에 안내한다.
- 로마자→가나 변환은 입력 편의 기능이다. 정답을 추측·추천하지 않으며, 영문 음절을 입력한 내용대로만 변환한다. 촉음·요음·ん·장음 입력을 지원하고 한 글자 지우기·모두 지우기를 제공한다.
- 정답 보기를 바로 누르면 '답 확인'으로 기록하며 정답률의 분자에 포함하지 않는다.
- 듣기 힌트를 사용하면 '힌트 사용'을 남긴다. 힌트 뒤의 정답은 무힌트 정답과 구분한다.
- 정답 공개 후에는 읽기·한국어 뜻·예문·발음 듣기·즐겨찾기를 보여준다.
- 카드 진행은 첫 평가 결과 기준으로 한 번만 집계한다. 재시도 이력은 별도로 남긴다.
- 음성 입력 실패·권한 거부·시간 초과·지원되지 않는 환경은 오답이 아니다.

### 음성 기반 단어 확인

언어는 ja-JP. 인식 후보의 한자·가나 표기를 검수된 허용 정답 목록과 비교한다. 인식 결과를 사용자에게 먼저 보여준다.

- 유니코드 정규화, 앞뒤 공백·구두점 제거, 가타카나→히라가나 변환을 적용한다.
- 장음, 촉음, 요음 차이는 자동으로 무시하지 않는다. 유사하다는 이유만으로 정답 처리하지 않는다.
- 한자 읽기는 짐작해서 변환하지 않는다. 허용 한자 표기와 읽기를 데이터에 명시한다.
- 복수 읽기·복수 의미 단어는 카드에서 출제한 읽기/의미의 허용 정답만 사용한다.
- 신뢰도가 낮거나 모호한 결과는 '다시 말해 주세요'로 안내하며 오답을 확정하지 않는다. 서비스마다 신뢰도 수치가 달라 전역 고정 점수는 설계하지 않는다.
- 문구는 '정답 단어로 인식했어요'로 한다. '발음 95점'처럼 발음 품질 평가를 주장하지 않는다.
- 녹음은 버튼을 누른 뒤에만 시작하고 취소/정지 수단을 제공한다. 기본적으로 원음은 저장하지 않는다.

### 다른 학습 모드

- 듣고 맞히기: 소리를 듣고 한국어 뜻 또는 그림 중에서 고른다. 정답 텍스트는 숨긴다.
- 따라 말하기: 정답과 소리를 공개하고 연습한다. 시험 정답률에 포함하지 않는다.
- 두 모드는 기본 카드 흐름을 완성한 뒤 추가한다. 현재 시안의 실제 작동 범위는 그림 보고 학습의 예시 상태다.

## 6. 복습·결과

초기 복습 간격은 1일 → 3일 → 7일 → 14일 → 30일로 단순화한다. 무힌트 정답이면 다음 단계로, 오답·답 확인·힌트 사용이면 1일 후로 배정한다. 인식 실패만 발생한 경우 단계와 복습일을 바꾸지 않는다. 별도 연습은 오늘의 최초 평가를 덮어쓰지 않는다.

결과에는 완료 카드 수, 무힌트 정답, 다시 연습, 답 확인/힌트 사용을 구분한다. 정확도는 `무힌트 정답 / 완료 카드 수`로 정의하고 0장일 때는 표시하지 않는다. 미완료와 인식 실패는 완료 수에 넣지 않는다.

## 7. 콘텐츠 원칙

- 수준 분류는 학습용 편집 기준이다. JLPT의 공식 전체 단어·문법 목록이라고 표기하지 않는다.
- 구체 명사는 사물 그림, 동사는 행동 그림, 추상어는 상황 그림을 사용한다.
- 단어가 숨겨진 문제에서는 그림 설명의 접근성 텍스트도 일본어 정답을 그대로 노출하지 않는다. 뜻 힌트 모드를 별도로 제공할 수 있다.
- 모호한 그림은 출제 후보에서 제외하거나 상황 힌트를 제공한다. 문맥으로도 구별할 수 없는 동의어는 음성 정답에 무작정 추가하지 않는다.
- 한국어 독음은 기본 콘텐츠에서 제외한다. 히라가나를 기본으로 하고 로마자는 선택 표시한다.
- 단어·예문·문법 설명·그림·음성마다 출처, 이용 조건, 검수 상태를 보관한다.
- 공개 콘텐츠는 의미·읽기·해설·예문·수준을 검수한다. 초안 데이터는 공개 학습 카드 선정에서 제외한다.

## 8. 설계 단계 완료 조건

- 홈·학습 앞/뒤·결과·단어장·문법·즐겨찾기·설정의 구성이 정해져 있다.
- 모바일 메뉴와 주요 학습 버튼이 PC와 동등한 기능을 제공한다.
- 날짜/수준 변경, 데이터 부족, 인식 실패, 정답 노출, 즐겨찾기 비어 있음의 규칙이 있다.
- 콘텐츠·개인 기록·세션·음성 결과를 분리한 데이터 계약이 있다.
- 시안 기능과 실제 구현이 필요한 기능을 명확히 구분한다.
