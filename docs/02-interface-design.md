# 화면·디자인 설계 v0.2

## 1. 시각 방향

가칭 '하루일본어'. 크림색 종이, 짙은 초록색 잉크, 부드러운 햇살을 떠올리는 일본어 학습 노트의 분위기다. 차분한 학습 도구를 지향한다. 수치로 검증되지 않은 학습 효과나 가짜 연속 학습 기록을 보여주지 않는다.

| 요소 | 기준 |
| --- | --- |
| 배경 / 표면 | #F7F6F1 / #FFFEFA |
| 본문 / 보조 글자 | #253A30 / #667268 |
| 주요 동작 | #285B45, 크림색 글자 |
| 부드러운 강조 | #EAF0E4, 세이지·연한 살구색 종이 |
| 주의/재시도 | #995B3E, 글과 아이콘을 함께 표시 |
| 모서리 | 목록 12px, 상세 18px, 학습 카드 22px, 홈 25px |
| 본문 | 16px, 줄 높이 1.65 이상 |
| 일본어 단어 | 40~58px, 히라가나 20~24px |
| 글꼴 | 한국어는 시스템 sans-serif, 일본어 대표 단어는 기기의 Mincho 계열 serif. 외부 폰트 다운로드 없음 |

표면 그림자는 절제하고, 화면의 핵심은 그림과 일본어 단어에 둔다. 홈에는 세이지·살구색 종이 카드가 겹친 모습을 배치한다. 카드는 실제 학습 데이터와 구분한 예시이며 선택 수준과 무관한 고양이 그림을 사용한다. 시안의 SVG 그림과 선형 아이콘은 직접 작성한 로컬 자산으로, 외부 이미지 서비스나 아이콘 CDN을 사용하지 않는다. 기본 배치는 styles.css, v0.2 시각 스타일은 polish.css에서 관리한다.

## 2. 정보 구조

```text
홈
├─ 오늘의 학습 → 문제 → 정답 공개 → 결과
├─ 단어장 → 단어 상세
│  └─ 즐겨찾기
├─ 문법 → 문법 상세
├─ 즐겨찾기 → 단어 상세 / 모아 학습
└─ 설정 → 수준·목표 / 표시·음성 / 저장·백업
```

오늘의 수준은 모든 목록에 강제로 적용하지 않는다. 목록마다 '전체' 또는 특정 수준을 선택할 수 있고, 목록 수준을 바꿔도 학습 설정이 바뀌지 않는다.

## 3. 화면별 명세

### 홈

- 오늘의 학습을 가장 크게 배치한다. 첫 방문에는 '오늘의 학습 시작', 진행 중에는 '이어서 학습'을 표시한다.
- 현재 수준과 하루 목표는 학습 시작 영역에 요약 표시한다. N1~N5 선택과 하루 학습량 조절은 홈에 두지 않는다.
- 홈은 오늘의 학습 카드 중심으로 구성한다. '조금 더 둘러보기'와 단어장·문법·즐겨찾기의 중복 링크를 두지 않고 PC 왼쪽 메뉴와 모바일 하단 탭을 사용한다.
- 현재 수준·하루 목표는 작은 요약으로 표시하고, 시작 버튼은 짙은 초록색의 주된 행동으로 강조한다. 장식용 카드에는 기능이 있는 것처럼 버튼을 만들지 않는다.
- 학습 방식과 현재 저장 방식 안내. 콘텐츠가 없으면 시작 대신 준비 중 상태와 설정으로 이동하는 동작을 제공한다.
- 시안은 오늘의 실제 통계 대신 '수준별 3장의 샘플 카드'임을 표시한다.

### 학습

- 상단: 학습 종류, 수준, 현재 카드/전체 수, 나가기.
- 앞면: 그림, 말하기/직접 입력, 정답 보기. 힌트는 보조 동작으로 구분한다.
- 직접 입력: 나의 답안 → 히라가나/가타카나 변환 후보 → 영문 입력 칸 → 입력 완료 순서로 배치한다. `neko` → `ねこ / ネコ`, `gakkou` → `がっこう / ガッコウ`처럼 입력 칸 위에서 후보를 선택한다. 후보는 정답 데이터와 무관하게 현재 입력에서 생성한다.
- 후보를 누르면 답안에 추가하고 영문 칸은 비운다. Enter는 히라가나 추가만 수행한다. 선택을 잘못했을 때 한 글자/전체 삭제할 수 있다. 로마자를 입력한 채 '입력 완료'를 눌러도 완성된 입력은 히라가나로 변환한다.
- 입력 도중의 자음과 잘못된 문자에는 안내를 표시하고 불완전한 후보 선택을 막는다. 한국어 IME 조합 중에는 자동 확정하거나 답을 공개하지 않는다. 모바일은 영어 입력 언어를 지정하고 자동 대문자·철자 교정을 끈다.
- 뒤: 한자, 히라가나, 뜻, 예문, 한국어 번역, 발음 듣기, 즐겨찾기, 다음 카드.
- 소리의 재생/정지와 녹음 동작은 독립적이며 동시에 동작하지 않는다.
- 정답 공개 이후 앞면으로 돌아가더라도 채점 결과는 되돌리지 않는다.
- 마지막에는 결과와 틀린 단어 재학습 진입을 제공한다.
- 시안의 '정답 예시 / 다시 연습 예시'는 화면 상태를 보여주는 도구이며 실제 음성을 처리하지 않는다.
- 예시 채점 버튼은 '채점 화면 미리보기'를 펼쳤을 때만 보여준다. 입력 모드에서는 그림의 높이를 줄여 답안·변환 후보에 집중할 수 있게 한다.

### 단어장·상세

- 상단 검색(일본어/읽기/한국어), 수준 필터, 결과 수.
- 목록 행: 단어·읽기·한국어 뜻·수준·즐겨찾기. 별 버튼은 상세 이동과 분리한다.
- PC에서는 목록과 상세를 나란히 배치한다.
- 목록은 간결한 종이 카드 형태, 선택한 행은 연한 초록색과 왼쪽 표시로 구분한다. 상세의 예문은 별도 배경으로 읽기와 번역을 묶는다.
- 모바일 상세는 목록 다음에 배치하고 선택 시 상세 위치로 이동한다. 실제 앱 구현 시 별도 상세 경로와 뒤로 가기를 제공한다.
- 결과가 없으면 검색어 지우기와 수준 전체 보기 동작을 제공한다.
- 읽기 여러 개인 단어는 상세에서 의미별로 구분한다.

### 문법·상세

- 수준 필터와 표현·한국어 해설 검색.
- 상세: 의미 → 접속 형태 → 사용 설명 → 예문·번역 → 주의점.
- 비슷한 문법 비교는 검수된 데이터가 있을 때만 표시한다.
- 시안은 수준별 문법 한 개를 제공한다. 빈 예문·가짜 오디오 재생 표시를 만들지 않는다.

### 즐겨찾기

- 저장한 단어 수, 수준 필터, 검색, 모아 학습 버튼.
- 비어 있을 때 '단어장에서 별을 눌러 모아 보세요'와 단어장 링크.
- 해제 시 목록을 갱신하고 선택한 상세가 사라지면 선택을 정리한다.
- 즐겨찾기 세션은 시작할 때 카드 ID를 고정한다. 세션 도중 해제해도 현재 진행 중인 카드가 사라지지 않는다.

### 설정

- 학습 수준·하루 목표는 이 화면에서만 변경한다. N5→N1 순으로 입문/초급/중급/중상급/고급 설명을 제공하고 하루 목표는 10/15/20장 중 선택한다.
- 로마자 표시, 음성 속도, 시간대도 이 화면에 둔다.
- 기기 내 저장과 기기 간 자동 동기화의 차이를 설명한다.
- 실제 구현에서는 기록 내보내기·가져오기, 저장 실패 안내를 제공한다.
- 데이터 삭제는 삭제 범위를 명시한 확인 대화상자가 필요하다. 시안에는 삭제 기능을 만들지 않는다.
- 현재 시안에서는 수준·목표·표시만 임시로 적용하고 저장 기능은 연결 전이라고 표시한다.
- '나의 학습'과 '읽기와 소리'를 같은 아이콘·제목·설명 구조로 구성한다. 학습량은 3개 버튼, 로마자 표시는 키보드로도 조작 가능한 체크박스 기반 스위치로 표현한다.

## 4. 반응형 배치

| 구간 | 화면 구성 |
| --- | --- |
| 1080px 이상 | 216px 왼쪽 메뉴 + 최대 1120px 본문. 홈과 학습은 보조 영역 포함 2열 |
| 720~1079px | 상단 브랜드·설정 + 하단 주요 메뉴. 내용은 가능한 경우 2열 |
| 320~719px | 단일 열, 가로 여백 16~20px, 화면 너비를 채운 카드, 하단 5개 메뉴 |

모바일 메뉴: 홈 / 학습 / 단어 / 문법 / 보관함. 설정은 상단의 텍스트 버튼으로 항상 접근 가능하다. 노치·홈바 영역에 safe-area 여백을 둔다. 키보드와 하단 메뉴가 버튼을 가리지 않게 입력 화면에서 추가 여백을 제공한다. 가로 회전에서도 높이가 고정되지 않게 한다.

## 5. 접근성과 동작

- 문서 기본 언어 ko, 일본어 표현과 읽기에는 lang=ja.
- 주요 터치 버튼 최소 44×44px, 색 이외에 문구로 정답/재시도 상태 구분.
- 카드 전체를 무분별하게 클릭 가능하게 하지 않고 '정답 보기' 버튼을 둔다. 뒤집기 상태를 스크린리더에 알린다.
- 검색 입력은 보이는 label을 제공한다. 별 버튼은 '○○ 즐겨찾기 추가/해제'라는 접근성 이름을 가진다.
- 포커스 윤곽선을 유지하고 화면 전환 시 본문 제목으로 초점을 이동한다.
- 상태 메시지는 aria-live=polite, 오류는 role=alert.
- prefers-reduced-motion에서는 카드·화면 전환 애니메이션을 없앤다.
- 키보드 단축키는 입력 중 작동하지 않게 하며, 기본 버튼 탐색만으로도 모든 기능을 사용할 수 있게 한다.
- 실제 출시에 앞서 기본 글자 대비, 200% 확대, 320px 너비, 키보드 순서와 모바일 스크린리더를 확인한다.

## 6. 상태 문구

| 상태 | 문구/동작 |
| --- | --- |
| 마이크 권한 없음 | '마이크를 사용할 수 없어요. 직접 입력으로 계속할 수 있어요.' |
| 음성 인식 실패 | '잘 듣지 못했어요. 다시 말하거나 직접 입력해 주세요.' |
| 지원 안 됨 | '이 브라우저에서는 말하기를 지원하지 않아요.' + 직접 입력 |
| 일본어 음성 없음 | '일본어 음성을 찾지 못했어요.' + 준비된 음성 또는 음성 설정 안내 |
| 정답 확인 | '정답 단어로 인식했어요.' 또는 '정답이에요.' |
| 재시도 | '읽기를 다시 확인해 볼까요?' + 정답 공개/다시 시도 |
| 저장 실패 | '이 기기에 기록을 저장하지 못했어요.' + 재시도/백업 안내 |
| 콘텐츠 부족 | '오늘은 준비된 카드 ○장으로 학습해요.' |
| 즐겨찾기 없음 | '다시 보고 싶은 단어를 모아 보세요.' + 단어장 |

## 7. 시안 검토와 미확정 항목

현재 확정한 기본값은 N5·15장·한국어 UI·기기 내 저장이다. 사용자 피드백으로 변경 가능한 항목은 제품명, 그림 스타일, 배경/포인트 색상, 초기 콘텐츠 확장 순서다. 이 항목들은 다음 구현을 막지 않는다.
